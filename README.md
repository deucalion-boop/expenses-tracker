# Expense Tracker

A full-stack personal expense tracker built with React + Vite on the frontend and Express + MongoDB on the backend.

## Features

- User authentication
- Income and expense tracking
- Dashboard summaries
- Analytics and recent transactions
- Responsive UI

## Tech Stack

- Frontend: React, Vite, React Router, Recharts
- Backend: Node.js, Express, MongoDB, Mongoose

## Getting Started

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Create a `.env` file in the backend using your MongoDB connection string and JWT secret.
